# **App Name**: ZaaykaTech Smart Menus

## Core Features:

- Digital Menu Display: Display interactive QR code menus with customizable branding.
- Mobile Ordering: Allow customers to place orders directly from their smartphones by scanning QR codes on tables or in hotel rooms.
- Admin Dashboard: Provide a centralized admin panel for restaurants to manage menus, orders, and subscriptions.
- Subscription Management: Manage subscription tiers, add-ons, and payment processing with yearly fee options.
- User Authentication: Secure user authentication using Firebase Auth for restaurants, admin, and customer users.
- Role-Based Authentication: Role-based authentication to differentiate between restaurant users, ZaaykaTech admin users, and customer roles.
- Analytics Display: Display analytics within the admin panel to view business performance. Add-on module only. Dynamic access based on subscription.
- AI Call Assistant: Use a generative AI tool to offer voice bot for order taking & confirmation. Add-on module only. Voice flow: Customer speaks order, AI confirms, sends to kitchen.
- Subscription Flow: Subscription flow including tiered pricing display and payment integration. Pricing comparison displayed in the dashboard.
- Backend Data Management: Store user data (plans, QR menus, orders) and perform backend operations. Features will show/hide based on subscription (dynamic access).
- Order Tracking & Billing: Live order tracking and printable bill generation.
- Offline Onboarding: Offline onboarding support for cash/UPI-based plan activations.

## Style Guidelines:

- Primary Accent: Warm Zaayka Orange (#F97316) for Buttons, Highlights, Active states
- Background Light: Cream White (#F9F7F2) for Page background, card backgrounds
- Text Primary: Charcoal Gray (#1F2937) for Headlines, primary text
- Text Secondary: Warm Gray (#6B7280) for Descriptions, sub-labels
- Surface/Card: Soft Beige (#F4EDE4) for Cards, section backgrounds
- Success Color: Fresh Mint (#10B981) for Order success, payment success
- Error/Alert Color: Soft Red (#EF4444) for Failed orders, alerts
- Body font: 'PT Sans' (sans-serif) for a clean, modern, easy-to-read appearance.
- Headline font: 'Playfair' (serif) for an elegant, fashionable, high-end feel. Use 'PT Sans' for body text when Playfair is used as a headline.
- Use clean and modern icons related to restaurant services.
- Subtle transitions and animations on user interactions for a smooth experience.
- Enhance UI with testimonials, 'As Used In' section, live demo QR, contact form, and WhatsApp floating chat. Full mobile responsiveness.
- Improve the pricing page display for better clarity and user experience.
- Hotel room ordering flow: customer scans QR, views menu, orders, and the order is sent to room service.
